# Prime Cost — Wendy’s F&B Bankruptcy Briefing

A single-page editorial briefing on **Meritage Hospitality Group’s** September 2026 Chapter 11 filing, centered on record food, paper, and labor (prime) costs at its Wendy’s restaurants.

Wendy’s corporate is not bankrupt. Meritage — one of the chain’s largest franchisees (314 stores) — cited an 18.9% beef-cost spike and prime costs peaking at **66.1% of sales**.

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
